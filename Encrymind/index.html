S0–S3 Security Tier Disclosure

把話說清楚：v1 為 S1 地端受控執行＋雙向密文封裝

我們拒絕把 S1 包裝成全程同態推論[cite: 8]。所有對外說明均同步揭露安全等級與推論邊界[cite: 8]。

等級 架構定義 密文智庫（EncryMind）版本狀態
S0 單向輸入加密套殼 嚴格廢棄，不採用單向加密架構[cite: 8]。
S1 地端受控執行＋雙向密文封裝 v1 交付基準：模型在設備隔離環境內推論，過程中有受控的短暫解密點（非全程密文運算），答案離開前再以會話金鑰封裝成密文[cite: 8]。
S2 密文域同態推論 研發／實驗模組，未通過效能與正確性測試前不標記為正式版（GA）[cite: 8]。
S3 任意雲端大模型雙向密文互動 明確排除，不保留任何改送雲端明文 API 之回退路徑[cite: 8]。
必揭露 S1 邊界聲明：密文智庫 v1 為 S1「地端受控執行＋雙向密文封裝」：問題以 USB 金鑰派生的會話金鑰加密送入，模型在設備隔離環境內推論（熱路徑存在受控短暫解密點），答案由回吐層以同一把會話金鑰封裝成密文送出，僅插著授權 USB 的人員看得到[cite: 8]。

Mandatory Behavioral Rules

六項強制行為規範（REQ-BEH-01 ～ 06）

從入口網關到地端儲存與日誌稽核，全程落實密文與金鑰邊界[cite: 8]。

REQ-BEH-01｜密文入鏈

入口網關拒收明文 Prompt

所有提問必須於客戶端以會話金鑰加密後送入，入口網關拒絕任何未加密的明文查詢請求[cite: 8]。

REQ-BEH-02｜密文回吐

地端模型回吐層雙向封裝

答案離開地端推論節點前，強制由模型回吐層（Model Cipher Egress Layer）以同一把會話金鑰封裝成密文[cite: 8]。

REQ-BEH-03｜USB 在位顯示

拔除 USB 立即清除前端明文

僅在授權 USB 硬體金鑰在位並通過驗證時解密顯示；拔除 USB 立即清除前端畫面明文[cite: 8]。

REQ-BEH-04｜NAS 原文封鎖

正式服務模式禁止明文匯出

知識庫以靜態加密存放於地端 NVMe/SATA 儲存區，正式服務模式下封鎖明文批次匯出[cite: 8]。

REQ-BEH-05｜命名空間隔離

無對應權限金鑰即阻斷檢索

依部門或專案切分命名空間（Namespace），未持有該命名空間授權金鑰者無法檢索相關知識[cite: 8]。

REQ-BEH-06｜零原文日誌

日誌僅記識別碼與密文雜湊

系統稽核日誌僅記錄 UUID、時間、Token 數、耗時與密文雜湊，絕不留存任何問題或答案原文[cite: 8]。

Frequently Asked Questions

常見問答（FAQ）

Q1：這是全程同態加密推論嗎？

v1 不是[cite: 8]。v1 為 S1：在地端隔離環境內受控解密並推論，回答再以會話金鑰封裝成密文；S2 為實驗模組，未通過效能與正確性測試前不標記 GA[cite: 8]。

Q2：可以接外部雲端的大模型嗎？

不行[cite: 8]。S3 明確排除任意雲端大模型的雙向密文互動，系統也不保留任何改送雲端明文 API 之回退路徑[cite: 8]。

Q3：AI NAS 硬體設備包含硬碟嗎？

AI NAS 個人型（2 槽）、小組型（4 槽）與全公司型（8 槽）均包含機殼與系統預裝，不含硬碟（方便企業依資安規範自行選購企業級 NVMe/SATA 硬碟）[cite: 1]。
