Key Boundary & FAIL-CLOSED Architecture

金鑰邊界、密文路由與本機明文防護

HEShell 是客戶端安全殼層與外部模型路由中繼——它不訓練、不微調模型，也不自行實作密碼學基元，而是把關金鑰邊界、路由規則與本機記憶體防護。

核心 01｜FAIL-CLOSED 路由

不支援密文就拒絕，絕不改送明文

檢查目標端點經簽章的密文能力宣告；若無合法 L1／L2 能力宣告，請求直接阻斷，沒有「改送明文」的後備路徑，出境封包若含自然語言明文字元即強制關閉連線。

核心 02｜複合金鑰與 USB 邊界

HE Provider 不能接觸到這把私鑰

HEShell 會從 HE Provider 取回一把加密過的私鑰，在您的電腦上當場組合成「複合金鑰」，存放在您手上的 USB 裡；HE Provider 不能接觸到這把私鑰，伺服器端不持有解密金鑰，您的提問明文也不會送往 HE Provider。

核心 03｜拔除即清除與記憶體鎖定

中止傳輸、白屏並抹除記憶體明文

USB 位於虛擬機的 USB 埠，可自行備份、遺失不補發、不做雲端備份（對外傳輸的是複合金鑰的組件，而非提問文字）。拔除 USB 即中止傳輸與運算、白屏並抹除記憶體明文；本機亦透過記憶體鎖定防止明文寫入交換區。

核心 04｜零明文日誌與誠實等待

四段階段指示器取代虛假串流

日誌僅記錄延遲、位元組數、錯誤碼與金鑰識別雜湊，並封鎖完整記憶體傾印。介面嚴禁假裝即時的逐字打字機串流，改以明確的四段階段指示器呈現批次等待。

介面階段指示器（四段階段）

  1. 金鑰封裝中
    於本機組合複合金鑰並加密使用者輸入。
  2. 密文傳輸中
    確認端點能力宣告後送出密文封包。
  3. 密文同態運算中
    端點於密文狀態下執行固定電路或模型運算。
  4. 接收結果
    取回運算結果並呈現於受保護畫面（結果以明文回傳）。
重要邊界與回傳路徑揭露：HEShell 的加密範圍為送出的使用者輸入，結果以明文回傳（與地端知識庫節點「密文智庫 EncryMind」以密文回傳至地端模型端不同）。S0 單向輸入加密架構（Legacy）是密文智庫文件裡的一種架構類型，非指特定產品且維持「嚴格廢棄」；HEShell 是已與 S0 不同的改版並繼續預售，採用 L0–L3 分級，不以 S0–S3 評級。
Capability Levels L0 — L3

L0–L3 能力分級（對外說明嚴格依此）

我們拒絕把「傳輸層加密」包裝成隱私賣點，亦不承諾超越現行密碼學技術限制的功能。

級別 技術定義 v1 產品狀態 說明與交付範圍
L0 傳輸層加密（TLS／HTTPS） 非本產品 伺服器端仍接觸明文，不列為 HEShell 的隱私賣點。
L1 指定 HE API 固定電路密文運算 本期交付 支援固定電路密文運算，例如 Embedding 比對、距離計算、數值評分與分類。
L2 端點密文模型推論 條件交付 端點密文推論，對使用者以明文回傳結果；僅限具備明確能力宣告之端點。
L3 任意閉源商用 LLM 直接處理密文即時生成 非現行科技 嚴禁承諾，不列入 v1 驗收與 Roadmap。
適用對象

高資安敏感團隊與 L2 端點持有者

  • 需要讓敏感輸入在運算端保持密文，執行比對、評分、分類等固定電路運算（L1）之組織與部門。
  • 已取得或自建具備能力宣告之 L2 密文推論端點，需要本機殼層統一處理金鑰、路由與拔除清除的技術團隊。
非對象（明確排除）

不適合使用 HEShell 的情境

  • 期待任意公有商用 LLM「全程加密、秒回」者（屬 L3 非現行科技，HEShell 會拒絕路由）。
  • 只需要傳輸層加密者（L0 非本產品），或需要地端私有知識庫與本地模型者（請參考「密文智庫 EncryMind」）。
Frequently Asked Questions

常見問答（FAQ）

Q1：可以用 HEShell 加密我們現在用的雲端 AI 聊天服務嗎？

不行。一般商用 LLM API 不能直接處理密文（L3 不是現行技術）；HEShell 只會把請求送往有明確密文能力宣告的端點，其餘一律拒絕。

Q2：v1 能做什麼？

L1 為指定 HE API 上的固定電路密文運算，例如 Embedding 比對、距離計算、數值評分與分類；L2 端點密文模型推論為條件交付，取決於端點是否具備並宣告此能力。

Q3：明文會送到外部 HE Provider 嗎？金鑰如何保存？

明文不會送到外部的 HE Provider。私鑰於本機當場組合為複合金鑰後存放於 USB，HE Provider 不能接觸到這把私鑰，伺服器端不持有解密金鑰。

Q4：回傳的結果也是加密的嗎？

不是。HEShell 的結果以明文回傳，加密範圍為送出的使用者輸入。

Q5：USB 遺失怎麼辦？系統會做雲端備份嗎？

可以自行備份 USB，但遺失不補發；不做雲端備份（對外傳輸的是複合金鑰的組件，而非提問文字）。USB 位於虛擬機的 USB 埠。
