L0–L3 Capability Grading

能力分級說清楚：L1 本期交付、L2 條件交付、L3 不承諾

許多「加密 AI」只加密了傳輸線路（TLS/HTTPS），伺服器端仍看得到明文[cite: 7]。在 HEShell 分級中，傳輸層加密（L0）不屬於本產品，也不列為隱私賣點[cite: 7]。

分級 技術定義 HEShell 交付與邊界狀態
L0 僅傳輸層加密（TLS / HTTPS） 伺服器端仍看得到明文，非本產品，不列為隱私賣點[cite: 7]。
L1 指定 HE API 固定電路密文運算 本期交付基準（如 Embedding 比對、距離計算、數值評分與分類）[cite: 7]。
L2 端點密文模型推論 條件交付，僅限具備經簽章 Capability Manifest 之端點[cite: 7]。
L3 任意閉源商用 LLM 直接處理密文 非現行科技，明確不承諾；無能力宣告即阻斷（HE_002）[cite: 7]。
回傳與金鑰邊界聲明：HEShell 不訓練也不微調任何模型，提問明文不會送到外部 HE Provider，伺服器端也不持有解密金鑰[cite: 7]。加密範圍為送出的使用者輸入，運算結果以明文回傳[cite: 7]。USB 金鑰不做雲端備份，遺失不補發[cite: 7]。

Four Defense Mechanisms

四項本機與路由防護設計

從出境封包檢查到本機記憶體鎖定，確保不留明文後備路徑[cite: 7]。

防護 01｜FAIL-CLOSED 零明文後備

無能力宣告即阻斷，出境檢查明文字元

檢查經簽章的 Capability Manifest，非 L1/L2 一律阻斷；出境封包若偵測到自然語言明文字元，立即強制關閉連線（HE_003）[cite: 7]。

防護 02｜USB 硬體金鑰邊界

秘密金鑰不經 API 上傳、禁止雲端備份

私鑰於本機組合成複合金鑰存於 USB，每次對話產生獨立 Session；拔除 USB 立即中止傳輸、白屏並抹除記憶體明文[cite: 7]。

防護 03｜本機記憶體防護

鎖定實體記憶體，防止寫入 Swap

透過 mlock / VirtualLock 鎖定敏感記憶體區段，防止明文資料被作業系統換頁寫入硬碟 Swap/Pagefile[cite: 7]。

防護 04｜誠實等待與零明文日誌

五段階段指示器，不假裝逐字串流

誠實呈現「金鑰封裝 → 密文傳輸 → 密文同態運算 → 密文下載 → 本機解密驗證」五階段；日誌僅記延遲、位元組數與錯誤碼[cite: 7]。

Frequently Asked Questions

常見問答（FAQ）

Q1：可以用 HEShell 加密我們現在用的雲端 AI 聊天服務嗎？

不行[cite: 7]。一般商用 LLM API 不能直接處理密文（L3 不是現行技術）；HEShell 只會把請求送往有明確密文能力宣告的端點，其餘一律拒絕[cite: 7]。

Q2：v1 目前能做哪些運算？

L1 為本期交付：指定 HE API 上的固定電路密文運算，例如 Embedding 比對、距離計算、數值評分與分類；L2 為條件交付，取決於端點能力[cite: 7]。

Q3：USB 金鑰需要另外購買嗎？
